# TastyKart — Project Overview
> Firebase-First Architecture Reference Document  
> Project ID: `tastykart-b791a` | Package: `com.arrowcoders.tastycartadmin`

## 1. Project Summary

TastyKart is a full-stack **food delivery admin panel** built with React 19 + TypeScript, backed entirely by Firebase. It is an internal tool used by the TastyKart operations team to manage restaurants, orders, delivery partners, earnings, payouts, promotions, and analytics for a multi-city food delivery platform operating in India.

| Attribute        | Value                                               |
|------------------|-----------------------------------------------------|
| Type             | Single-Page Application (SPA) — Admin Panel         |
| Framework        | React 19 + TypeScript + Vite 8                      |
| Styling          | Tailwind CSS v4 + Radix UI + Framer Motion          |
| Firebase SDK     | v12.17.0 (Web modular API)                          |
| Firebase Project | `tastykart-b791a`                                   |
| Auth Domain      | `tastykart-b791a.firebaseapp.com`                   |
| Storage Bucket   | `tastykart-b791a.firebasestorage.app`               |
| Hosting Target   | Firebase Hosting → `dist/` (SPA rewrites)           |
| Cloud Functions  | Node.js 20 runtime (TypeScript)                     |
| Analytics        | Firebase Analytics (`G-3C5EJ35NNB`)                 |
| Deployment       | `firebase deploy` (hosting + functions + firestore) |

| `isActive`          | boolean | Level active flag                         |
| `earningMultiplier` | number  | Earning bonus multiplier for this level   |

**Level scoring algorithm (Cloud Function):**
```
levelScore = (totalEarnings / 1000 × 0.3) + (completedOrders × 0.1) + (avgRating × 5)

BRONZE   → score < 100
SILVER   → score 100–299
GOLD     → score 300–499
PLATINUM → score ≥ 500
```

## 7. Cloud Functions (`functions/src/index.ts`)

Runtime: **Node.js 20** | Language: **TypeScript**

### 7.1 Firestore Trigger: `onOrderCompleted`
- **Trigger:** `orders/{orderId}` document update
- **Fires when:** `status` changes to `COMPLETED`
- **Actions:**
  1. Fetch highest-priority active earning rule
  2. Apply peak-hour / night multipliers
  3. Create `earnings` record
  4. Create idempotent `walletTransactions` entry (type: `ORDER_EARNING`)
  5. Increment partner `totalEarnings`, `walletBalance`, `totalCompletedOrders`
  6. Write `adminAuditLog` entry

### 7.2 Firestore Trigger: `onPartnerEarningsUpdated`
- **Trigger:** `deliveryPartners/{partnerId}` document update
- **Fires when:** `totalEarnings` changes
- **Actions:**
  1. Fetch all active `EARNINGS` / `HYBRID` incentive campaigns
  2. Match partner against campaign tiers
  3. If qualifying tier found and not yet rewarded → create `INCENTIVE` wallet transaction
  4. Update `incentiveProgress` doc
  5. Increment partner `walletBalance` and `incentivesEarned`

### 7.3 Callable: `approvePayout`
- **Caller:** Finance admin from Payouts page
- **Actions (Firestore transaction):**
  1. Verify payout status is `PENDING`
  2. Update `payoutRequests` → `APPROVED`
  3. Create `DEBIT` wallet transaction (type: `PAYOUT`)
  4. Decrement partner `walletBalance`
  5. Write audit log

### 7.4 Callable: `rejectPayout`
- **Caller:** Finance admin from Payouts page
- **Actions:**
  1. Verify payout status is `PENDING`
  2. Update `payoutRequests` → `REJECTED` with reason
  3. Write audit log

### 7.5 Callable: `calculatePartnerLevel`
- **Caller:** Admin or scheduled job
- **Logic:** Computes `levelScore` from `totalEarnings`, `totalCompletedOrders`, `avgRating`
- **Updates:** `partnerLevel` (BRONZE/SILVER/GOLD/PLATINUM), `levelScore`, `levelCalculatedAt`

### 7.6 Scheduled: `cleanupOldAuditLogs`
- **Schedule:** Daily at 02:00
- **Action:** Batch delete `adminAuditLog` entries older than 90 days (max 1000/run)

## 14. Earning & Payout Flow (End-to-End)

```
1. Order created → status: pending
2. Partner accepts → status: accepted
3. Restaurant prepares → status: preparing → ready
4. Partner picks up → status: picked (pickedAt timestamp)
5. Partner delivers → status: delivered / COMPLETED
      ↓
6. Cloud Function: onOrderCompleted fires
      ↓
7. Fetch active earningRule (highest priority)
8. Apply peakHour / night multipliers
9. Create earnings/{earningId} record
10. Create walletTransactions/{idempotencyKey} (CREDIT)
11. Update deliveryPartners/{id}:
    - totalEarnings += finalEarning
    - walletBalance += finalEarning
    - totalCompletedOrders += 1
      ↓
12. onPartnerEarningsUpdated fires (earnings delta)
13. Check active EARNINGS/HYBRID incentive campaigns
14. If tier threshold met → create INCENTIVE wallet transaction
15. Update incentiveProgress + walletBalance
      ↓
16. Partner requests payout (admin panel)
17. Admin approves → approvePayout callable
18. Firestore transaction:
    - payoutRequests → APPROVED
    - walletTransactions DEBIT (PAYOUT type)
    - walletBalance -= approvedAmount
    - adminAuditLog entry
```

## 16. Partner Level Determination

```
Score Calculation:
  + (totalEarnings / 1000) × 0.3   → earnings contribution
  + totalCompletedOrders × 0.1     → volume contribution
  + avgRating × 5                  → quality contribution

Level Assignment:
  BRONZE   → score < 100
  SILVER   → 100 ≤ score < 300
  GOLD     → 300 ≤ score < 500
  PLATINUM → score ≥ 500

Recalculated by:
  - Admin-triggered callable (calculatePartnerLevel)
  - Can also be run as scheduled function
```
